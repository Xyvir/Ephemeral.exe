This client auto-connects to the cluster: it fetches the live swarm list (docs/swarm.json, refreshed every 6 hours) and dials current members — the public build ships with no compiled-in seeds — no user input needed. Nodes are discovered automatically and jobs route to the best available compute node (warm image first, then lowest latency). All traffic goes through an iroh relay — the public n0 relays by default, or a self-hosted one below.
